# 🎫 Laravel Ticketsystem

Ein einfaches Ticketsystem, das im Rahmen meiner Laravel-Weiterbildung entwickelt wurde.

Ziel des Projekts ist es, grundlegende Laravel-Konzepte praktisch anzuwenden und ein kleines CRUD-System zur Verwaltung von Tickets zu erstellen.

## 🚀 Funktionen

- Tickets erstellen
- Tickets anzeigen
- Tickets bearbeiten
- Tickets löschen
- Ticket-Status verwalten
- Prioritäten festlegen
- Tickets nach Kategorien organisieren
- Formulareingaben validieren
- Daten in einer MySQL-Datenbank speichern

## 🛠️ Technologien

Das Projekt verwendet:

- PHP
- Laravel
- Blade
- Tailwind CSS
- MySQL
- Laravel Sail
- Docker
- Git / GitHub

## 📚 Verwendete Laravel-Konzepte

In diesem Projekt wurden unter anderem folgende Laravel-Konzepte eingesetzt:

- Routing
- Resource Controller
- Models
- Eloquent ORM
- Migrations
- Blade Templates
- Blade Components
- Form Validation
- Middleware
- CRUD-Operationen
- Database Seeding
